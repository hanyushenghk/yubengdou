# Yubengdou — Hong Kong Child Growth Services Demo

Desktop-only e-commerce and service platform: Traditional Chinese HK (default), Simplified Chinese, English.

## Functional scope
Customer storefront, parent accounts, tutor workbench, admin console; catalog, cart, ordering, mock payment, bookings, dispatch, service plans/feedback, hour-card ledger, content administration.

## Stack
Next.js App Router / TypeScript / Tailwind CSS / shadcn-ui / next-intl / PostgreSQL / Drizzle / Better Auth / Vitest / Playwright.

## Payment constraint
No bank gateway in demo. Implement demo-only mock payment success, failure, refund, no real charges.
